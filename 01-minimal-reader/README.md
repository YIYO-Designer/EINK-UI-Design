# 01 · 黑白极简阅读器 / Minimal Reader

以阅读为核心，回归墨水屏本身的纸感与秩序。通过黑白灰、高对比文字、粗描边圆角容器和胶囊导航，建立轻量、直观的阅读界面。

## 设计规格

- 画布：684 × 1216 px（竖屏）
- 色彩：黑、白及中性灰；面向灰阶墨水屏设计
- 字体：系统界面采用粗黑体风格，正文采用具有书写感的中文字体
- 导航：首页、书架、设置；当前项黑底白字

## 页面说明

| 页面 | 设计要点 |
| --- | --- |
| 首页 | 大幅书籍封面作为视觉中心，保留继续阅读入口与简洁状态栏 |
| 书架 | 全部、在读、未读分类；序号、书名、进度及分页，虚线分隔列表 |
| 设置 | 设备信息与独立圆角设置条目，展示亮度、翻页方式、休眠、网络、存储和设备信息 |
| 正文阅读 | 隐藏一级导航，突出正文，以虚线行底纹、页码及底部进度条营造纸质阅读感 |

## 设计理念

减少非必要装饰与操作入口，以明确的信息层级降低认知负担。通过反白选中状态替代彩色提示，以稳定布局和低复杂度控件适配电子纸的显示特性。实际刷新策略、触控命中区域、字体渲染和硬件功能仍需固件开发与实机测试。
